# Policies
1. Never modify live files, repos, or the snapshot. Work in work/ only.
2. Never commit, push, upload, or send anything. Hand back in chat only.
3. Never print or ask for tokens or credentials.
4. IDs come from almanac only. Specs and tasks never name agents.
5. TOML, never JSON, for data. Keep filenames exactly as given.
6. No paid services (such as OCR) without the user's approval.
7. If an input refers to another of the user's documents that isn't attached, stop and say so.
8. When unsure whether an item is a task, add it to coverage.md as `dropped: needs decision (question)` instead of guessing.
